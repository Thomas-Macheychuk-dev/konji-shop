Before apply it checks exact current identity/SEO/body hashes, every variant identity/status/option, producer/product-attribute values, and reviewed image-source links. It records all target image rows in the private plan, locks them with the affected rows and refuses source/media/variant drift. SEO, names and captions commit in one outer transaction and verify together. After-state verification uses a derived manifest with the reviewed new names; rollback verifies that same state before restoring exact old names, metadata, matching captions and timestamps. Later manual edits block rollback. Existing shared engines and checksums stay unchanged. Catalogue and navigation namespaces are invalidated after apply/rollback; all active rendered metadata is checked.
